# Cloudflare R2 파일 저장 설정 가이드

게시판 사진·자료실 파일을 Cloudflare R2(무료 10GB·전송 무료)에 저장하기 위한 설정입니다.
대시보드에서 클릭 몇 번이면 됩니다. (비밀키는 코드에 넣지 않습니다 — Worker '바인딩'으로 안전 연결)

## 1) R2 버킷 만들기
1. Cloudflare 대시보드 → 왼쪽 **R2 Object Storage**(스토리지 및 데이터베이스 안)
2. **Create bucket** → 이름 `church-uploads` → 생성
   - (처음이면 R2 사용 시작에 카드 등록이 필요할 수 있으나, 무료 한도 내에선 과금 안 됨)

## 2) Worker 만들기
1. 왼쪽 **Compute(컴퓨트) → Workers 및 Pages** → **Create application → Create Worker**
2. 이름 `church-files` → **Deploy**(일단 기본 코드로 배포)
3. **Edit code**(코드 편집) → 기존 내용 전부 지우고 → `cloudflare/worker.js` 내용 전체 붙여넣기 → **Deploy**

## 3) Worker에 값/버킷 연결 (Settings)
Worker 화면의 **Settings** 탭에서:

**① Variables and Secrets** (일반 변수 2개 추가)
| 이름 | 값 |
|---|---|
| `SUPABASE_URL` | `https://cetacttsdwzxjzkyozgd.supabase.co` |
| `SUPABASE_ANON_KEY` | `sb_publishable_qfq4Hvs4tF_1ZIezPoMojg_h6XNw01G` |

**② Bindings → Add → R2 bucket**
| 항목 | 값 |
|---|---|
| Variable name | `BUCKET` ← 반드시 이 이름 |
| R2 bucket | `church-uploads` |

추가 후 다시 **Deploy**.

**③ (선택) 임시 비밀번호 발급 — 담임목사 전용 기능**

비밀번호를 잊은 이메일 가입 성도에게 담임목사가 목회행정 대시보드에서
임시 비밀번호를 만들어 전화·문자로 전달하는 기능입니다.
**Variables and Secrets**에 **Secret**(암호화) 타입으로 2개 추가:

| 이름 | 값 |
|---|---|
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase 대시보드 → Settings → API → `service_role` 키 (**절대 공개 금지**) |
| `SUPER_ADMIN_EMAIL` | 담임목사 로그인 이메일 (예: `kds08200820@gmail.com`) |

추가 후 다시 **Deploy**. 미설정 시 이 기능만 "설정 필요"로 표시되고 나머지는 정상입니다.
- 이 기능은 `SUPER_ADMIN_EMAIL`과 정확히 같은 이메일로 로그인한 관리자만 쓸 수 있습니다.
- 카카오 가입 계정과 다른 관리자 계정의 비밀번호는 바꿀 수 없게 막혀 있습니다.

## 4) Worker 주소 알려주기
배포되면 주소가 생깁니다: `https://church-files.<계정이름>.workers.dev`
→ 이 주소를 알려주시면 제가 `js/config.js`의 `window.R2_UPLOAD_URL`에 넣고
게시판 사진 첨부 + 자료실 R2 전환을 마무리합니다.

## 동작 요약
- 업로드: 로그인 교인만 → 브라우저에서 자동 압축 → Worker가 R2에 저장
- 보기: `…workers.dev/f/키` 로 누구나 열람(1년 캐시)
- 삭제: 본인이 올린 파일만 가능

# 오디오북(정회원 전용) 추가 설정

책 «레위기에서 만난 예수 그리스도» 낭독 음원은 판매 중인 책의 전문이라
**공개 주소(`/f/`)로는 열리지 않게** 막아 두었습니다.
정회원임을 확인한 사람에게만 **6시간짜리 재생 열쇠(서명)** 를 내주고,
그 서명이 붙은 주소로만 들려줍니다. 아래 한 가지만 더 넣으시면 됩니다.

## 1) 비밀값 1개 추가
Worker 화면 → **Settings → Variables and Secrets → Add → Secret**

| 이름 | 값 |
|---|---|
| `BOOK_AUDIO_SECRET` | 아무도 모르는 긴 무작위 문자열(24자 이상) |

값 만들기 예시 — 명령 프롬프트에서:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

나온 문자열을 그대로 붙여 넣으세요. **이 값은 어디에도 적어 두지 마세요**
(잃어버려도 새 값을 넣으면 그만입니다 — 이미 열려 있던 재생 창만 새로고침하면 됩니다).

넣은 뒤 **Deploy**.

> 이 값을 넣지 않으면 오디오북 재생만 "설정이 아직 끝나지 않았습니다"로 막히고,
> 사진·자료실·성경 음원 등 나머지 기능은 그대로 동작합니다.

## 2) 음원 올리기 (교회 PC)
GPT-SoVITS를 켜 둔 상태에서:

```bash
node tools/audiobook_tts.mjs --all
```

- 여는 글 · 1~27장 · 닫는 글 = **29개 트랙**을 만들어 R2 `audiobook/` 에 올립니다.
- 이미 올라간 장은 건너뜁니다(중간에 끊겨도 다시 실행하면 이어서 진행).
- 대본을 고쳤다면 `python tools/audiobook_split.py` 를 먼저 다시 실행하세요.

## 3) 확인
- **목회행정 → 📚 오디오북 음원 관리** 카드에 `29/29` 로 뜨면 완료.
  (카드를 누르면 장별 미리듣기·삭제가 됩니다)
- 홈페이지 **말씀으로 → 오디오북 듣기** 에서 정회원 계정으로 재생 확인.

## 경로 정리
| 경로 | 누가 | 하는 일 |
|---|---|---|
| `POST /book-audio` | 관리자 | 음원 올리기(`x-book-name` 헤더에 파일 이름) |
| `POST /book-audio-list` | 관리자 | 올라온 음원 목록 |
| `POST /book-audio-delete` | 관리자 | 음원 삭제 |
| `POST /book-audio-url` | **정회원**·관리자 | 6시간짜리 재생 열쇠 발급 |
| `GET /book-audio/<이름>` | 열쇠 가진 사람 | 재생(구간 이동·이어듣기 지원) |
| `GET /f/audiobook/…` | — | **항상 거부**(공개 유출 차단) |

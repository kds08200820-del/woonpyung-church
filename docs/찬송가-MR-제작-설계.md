# 새찬송가 MR 제작 설계 (악보 → 반주)

2026-11-13 · 담임목사 지시: "악보를 토대로 MR 을 만들어야 합니다. 전주 + 전곡 연주."

## 1. 왜 다시 만드나

- 유튜브 MR(재생목록)은 절 사이에 간주가 들어가서 예배 때 쓸 수 없다. 그래서 11/13 연동을 뺐다(main 000780b).
- 새 MR 은 **교회가 가진 악보 그림을 그대로 연주**한다. 간주는 넣지 않는다.

## 2. 재료

- 악보: `OneDrive\바탕 화면\예배준비 폴더\찬송가\새찬송가_NNN장.jpg`
  - 644장 (1~645장, **40장이 없음**). 한 장의 크기는 가로 약 1,400 픽셀이다.
  - 4성부(소프라노·알토·테너·베이스) 악보, 코드, 빠르기말(예: "보통으로"), 절 가사 줄, "아멘"이 들어 있다.
- 305장으로 살펴본 결과, 인쇄가 깨끗하고 오선이 곧아서 기계가 읽기에 좋은 악보다.

## 3. 만드는 순서

```
악보 그림 ──① 악보 읽기──▶ MusicXML ──② 점검──▶ ③ 편곡 규칙 ──▶ MIDI ──④ 소리 만들기──▶ m4a ──⑤ 올리기──▶ ⑥ 화면에서 틀기
```

### ① 악보 읽기 (OMR)
- 도구: **Audiveris 5.11** (무료·오픈소스. 악보 그림을 MusicXML 로 바꾼다)
- 음표·쉼표·박자·조표·붙임줄·페르마타를 읽는다. 한글 가사는 잘 읽지 못하므로 가사는 쓰지 않는다.
- 교회 PC 에서 한 장에 30초~1분 걸린다. GPU 는 쓰지 않으므로 새벽 영상 제작과 겹쳐도 된다.

### ② 점검 (가장 중요)
기계가 잘못 읽은 음이 하나만 있어도 예배 때 틀린 음이 난다. 그래서 두 번 점검한다.
1. **자동 검사**: 마디마다 박자의 합이 맞는지, 네 성부가 모두 있는지, 음이 성부 음역 안에 있는지, 처음과 끝 화음이 조성과 맞는지 본다.
2. **눈 대조**: 읽은 악보를 다시 그림으로 그려 원래 악보와 나란히 놓고 Claude 가 마디마다 비교한다. 다른 곳은 고친다. 끝까지 자신 없는 장은 「확인 필요」 목록으로 남긴다.
- 절 수와 "아멘" 여부는 악보 그림을 보고 표에 적는다(예: 305장 = 4절, 아멘 있음).

### ③ 편곡 규칙 (전주 + 전곡)
| 항목 | 규칙 (기본값, 장마다 바꿀 수 있음) |
|---|---|
| 전주 | **마지막 4마디**(마지막 한 줄). 다른 방법은 「전곡 한 번」이다. → 결정 필요 ① |
| 본 연주 | 1절부터 끝 절까지 악보 그대로 반복한다. **간주는 넣지 않는다** |
| 절 사이 | 마지막 음을 악보 길이대로 끝낸 다음 숨 쉴 틈만 둔다(기본 1박) |
| 끝 | 마지막 절의 마지막 줄은 조금 느려진다(ritardando). 악보에 아멘이 있으면 마지막 절 뒤에 한 번만 연주한다 |
| 빠르기 | 빠르기말을 BPM 으로 정한다(보통으로 = 4분음표 84 등). 장마다 고칠 수 있다 |
| 못갖춘마디 | 첫 마디가 못갖춘마디이면, 전주 끝과 절 사이에서 박을 맞춘다 |
| 페르마타 | 그 음을 1.5배로 늘인다 |

### ④ 소리 만들기 — 웅장한 오케스트라
목사님이 보내 주신 참고 영상(「만복의 근원」, 3분)의 느낌을 목표로 한다. 이 영상은 전주가 약 12초이고, 조용하게 시작해서 절마다 커지며, 마지막 절이 가장 크고, 울림이 큰 홀 소리를 낸다.

- **악기 배치(4성부 → 오케스트라)**
  | 악보 성부 | 맡는 악기 |
  |---|---|
  | 소프라노(멜로디) | 바이올린 1 + 플루트, 마지막 절은 트럼펫을 더함 |
  | 알토 | 바이올린 2 + 클라리넷 |
  | 테너 | 비올라 + 호른 |
  | 베이스 | 첼로 + 콘트라베이스, 마지막 절은 트롬본·튜바를 더함 |
  | 바탕 | 파이프 오르간을 낮게, 절이 끝나는 화음에 팀파니 |
- **절마다 커지기**: 전주와 1절은 현악과 목관으로 부드럽게 한다. 가운데 절들은 호른을 더한다. 마지막 절은 금관 전체와 팀파니를 넣고 가장 크게 한다. 음과 박은 악보 그대로 두고, 악기 수와 세기만 바꾼다.
- **도구**: MIDI → **sfizz**(무료 SFZ 연주기) + **VSCO 2 CE** 오케스트라 음원(CC0, 누구나 자유롭게 쓸 수 있음) → WAV → 홀 울림(잔향) → 소리 크기 맞춤(loudnorm) → m4a 192k.
- 4절 찬송은 3분쯤, 4~5MB 쯤이다.
- 참고 영상만큼 풍성한 소리가 나는지는 시범 곡으로 들어 봐야 안다. 부족하면 아래 5절의 「AI 다듬기」를 시험한다.

### ⑤ 올리기
- 교회 파일 저장소 `hymnmr/NNN.m4a`에 올린다(영상과 같은 저장소).
- 목록 파일에 장·절 수·빠르기·길이·주소·판 번호를 적는다. 다시 만들면 판 번호를 올려서 옛 파일이 브라우저에 남지 않게 한다.

### ⑥ 화면
- 모두의 찬송, 오늘의 예배(찬송 악보), 발표자 모드에 **「반주」 단추**를 넣는다.
- 그 화면 안에서 재생하고, 정지·처음부터 단추를 둔다. 지금 몇 절째인지 보이게 한다.
- 영상이 없으므로 유튜브 창 문제(차단·간주)는 생기지 않는다.

## 4. 진행 단계
1. **시범 10장**: 305·1·8·94·250·288·310·405·438·545장(박자와 조가 서로 다른 곡들). 교회 PC 에서 만들어 목사님이 듣고 확인하신다.
2. 확인이 되면 **나머지 634장**을 만든다. 하룻밤에 100~200장(GPU 를 쓰지 않음). 「확인 필요」 장은 따로 보고한다.
3. 화면에 연결하고 배포한다.

## 5. AI 음악 모델 (Lyria 3 같은 것)
- **Lyria 3** 는 구글 서비스로만 제공된다. 내려받아 로컬에서 돌릴 수 없다.
- 로컬에서 돌릴 수 있는 것은 **ACE-Step 1.5**(ComfyUI 지원, 10GB)다. 참고 영상 같은 웅장한 곡을 만들 수 있다. 하지만 이 모델은 곡을 **새로 짓는다**. 악보의 음과 박을 그대로 지키지 못하고, 간주를 마음대로 넣을 수도 있다. 회중이 따라 부르는 반주로는 그대로 쓸 수 없다.
- **AI 다듬기(시험)**: ④에서 악보대로 만든 오케스트라 소리를 ACE-Step 의 「따라 연주하기(cover/audio-to-audio)」에 넣어 소리만 더 풍성하게 바꿔 본다. 그 결과를 원래 MIDI 와 자동으로 맞춰 보고(박 위치·음높이·길이), 하나라도 어긋나면 버리고 ④의 소리를 쓴다. 이 기능은 ComfyUI 에서는 아직 준비 중이라 ACE-Step 자체 프로그램으로 시험한다.
- 순서: ④로 시범 곡을 먼저 만든다. 목사님이 소리가 부족하다고 하시면 그때 ACE-Step 을 설치해 AI 다듬기를 시험한다.

## 7. 목사님이 정하실 것
1. 전주: 마지막 4마디로 할까요, 전곡을 한 번 연주할까요?
2. 악기: 오케스트라 한 가지로 할까요, 피아노판(작은 모임·새벽기도용)도 함께 만들까요?
3. 공개 범위: 새찬송가 악보·편곡은 한국찬송가공회 저작물이고, 한국 작곡가 곡은 저작권이 살아 있다. MR 을 교회 안(로그인한 성도·예배 화면)에서만 틀까요, 누구나 듣게 할까요? → 로그인한 사람에게만 틀기를 권한다.

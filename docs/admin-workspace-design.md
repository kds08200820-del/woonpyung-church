# 관리자 화면 디자인 (2026-10-30)

## 적용 범위와 파일

- css/admin-workspace.css: 관리 화면에서만 쓰는 공통 화면 테마.
- affairs.html: 목회행정 전체 하위 메뉴에 공통 테마 연결.
- admin.html: 회원 관리 테마 연결.
- finance.html: 재정관리 테마 연결.
- gyojeok.html: 교적관리 테마 연결.
- ax.html: AX 관제실 테마 연결.
- js/affairs.js: 기존 메뉴 텍스트 앞에 장식용 SVG 아이콘 추가. 기존 data-t, 클릭 핸들러와 권한 확인 유지.

관리 화면 body에 management-ui 클래스를 붙인다. 일반 홈페이지와 별도 출력 창에는 적용하지 않는다. 모든 테마 규칙은 @media screen 안에 두어 인쇄 시 기존 양식을 유지한다. 설교 원고 내용, 문서 용지와 PDF의 글꼴·치수는 변경하지 않는다.

## 시각 기준

- 바탕 #f3f6fa, 본문 #1d293d, 사이드바 #142238, 주요 동작 #176b66.
- 흰색 작업 패널, 8~14px 모서리, 얇은 경계선과 제한적인 그림자.
- 캘린더의 예배별 색상은 유지한다. 긴 제목은 줄바꿈하고 모바일에서는 날짜별 목록을 사용한다.
- 모바일 메뉴는 가로 스크롤을 사용한다. 표는 화면 안에서 가로 스크롤한다.
- 키보드 초점과 선택 상태를 구분하고 움직임 감소 설정을 존중한다.

- 모바일 설교 캘린더 1열 전환과 메뉴 가로 스크롤 확인.
- 설교 편집기 열림, UI 테마 적용, 편집 영역 존재 확인. 실제 원고의 저장·수정은 수행하지 않음.

# 오늘의 QT 카카오톡 단톡방 자동 발송

보내는 방법은 두 가지입니다.

| | 매일 자동 발송 | 홈페이지 예약 발송 |
| --- | --- | --- |
| 시작하는 곳 | Windows 작업 스케줄러 (매일 06:00) | 설교 매니저 → **⏰ 예약 발송** |
| 보낼 내용 | 그날 홈페이지 QT를 그때 가져옴 | 예약할 때의 내용을 그대로 저장 |
| 채널 | 설정 파일의 방 1개 | 예약창에서 여러 방 선택 |
| 시각 | 매일 같은 시각 | 건마다 지정 |
| 보내는 프로그램 | `tools/카카오QT_발송.bat` | `tools/kakao_worker.py` |

둘 다 같은 발송 엔진(`tools/kakao_qt_send.py`)을 쓰므로 안전장치도 같습니다.
아래 **처음 한 번만 해야 할 설정**(자동 로그인·잠금모드)은 두 방식 모두에 필요합니다.

---

## 매일 자동 발송

매일 정해진 시각에 홈페이지의 **오늘의 QT 전문**을 카카오톡 단톡방으로 자동 발송합니다.

- 스크립트: `tools/kakao_qt_send.py`
- 실행 배치: `tools/카카오QT_발송.bat`
- 스케줄 등록: `tools/register_kakao_qt_task.ps1`
- 설정: `tools/kakao_qt_config.json` (공개 저장소에 올리지 않음 — `.example.json` 참고)
- 로그: `tools/logs/kakao_qt.log`

---

## 왜 이런 방식인가

카카오 공식 메시지 API로는 **단톡방에 보낼 수 없습니다.** 공식 지원 범위는
`나에게 보내기`와 `친구 1:1 보내기`뿐이고, 기존 단톡방·오픈채팅방 발송 API는
제공되지 않습니다(카카오 개발자 포럼의 반복된 답변).

그래서 이미 로그인돼 있는 **카카오톡 PC 창을 직접 조작**합니다.

### 두 가지 함정 (직접 부딪혀 확인한 것)

1. **`WM_SETTEXT`로 글자만 넣으면 전송되지 않습니다.**
   컨트롤에는 글이 보이지만 카카오톡 내부 입력 버퍼는 "비어 있다"고 인식해,
   Enter를 눌러도 보낼 것이 없다고 판단하고 아무 일도 일어나지 않습니다.
   → 실제 사용자 입력과 같은 경로인 **클립보드 붙여넣기(Ctrl+V) + 실제 Enter 키**를 씁니다.

2. **빈 입력창에는 안내 문구 `"메시지 입력"`이 실제 텍스트로 들어 있습니다.**
   `WM_GETTEXT`로는 사용자가 쓴 글과 구분되지 않아, 걸러내지 않으면
   전송 성공을 실패로 오판하고 안내 문구를 진짜 입력처럼 되돌려 써넣습니다.

## 처음 한 번만 해야 할 설정

### 1. 카카오톡 PC '자동 로그인' 켜기 — **필수**

스크립트는 **비밀번호를 입력하지 않습니다.** 보안상 의도적으로 그렇게 만들었습니다
(스케줄러·스크립트·로그 어디에도 비밀번호가 남지 않습니다).

카카오톡 PC → 설정 → 개인/보안 → **자동 로그인 사용** 체크.

로그인이 풀려 있으면 스크립트는 카카오톡을 실행만 하고, 로그인 창을 넘지 못하면
발송을 포기하고 로그에 안내를 남깁니다.

### 2. 잠금모드 끄기 (또는 해제해 두기)

잠금모드가 켜져 있으면 발송하지 않고 중단합니다. 비밀번호를 대신 입력하지 않기 때문입니다.

### 3. 단톡방 이름 설정

`tools/kakao_qt_config.example.json` 을 `tools/kakao_qt_config.json` 으로 복사하고
`room_name` 에 **카카오톡에 보이는 방 이름을 그대로** 적습니다.

```json
{
  "room_name": "에클레시아 운평",
  "kakao_exe": "C:\\Program Files (x86)\\Kakao\\KakaoTalk\\KakaoTalk.exe",
  "max_chars": 4000
}
```

방 이름이 바뀌면 이 파일도 같이 고쳐야 합니다. 이름이 다르면 **발송하지 않고 중단**합니다
(엉뚱한 방에 보내는 사고를 막기 위해 제목이 정확히 일치할 때만 보냅니다).

### 4. 스케줄 등록

```powershell
powershell -ExecutionPolicy Bypass -File "tools\register_kakao_qt_task.ps1"
```

시간을 바꾸려면 `-Time "05:40"`, 해제하려면 `-Unregister` 를 붙입니다.

## 안전장치

- **오늘 QT가 없으면 건너뜁니다.** 어제 QT를 대신 보내지 않습니다(종료 코드 2).
- **같은 날 두 번 보내지 않습니다.** `tools/logs/kakao_qt_state.json` 에 기록합니다.
- **방 제목이 정확히 일치할 때만** 보냅니다.
- **잠금모드면 중단**합니다.
- **쓰다 만 글을 지우지 않습니다.** 입력창에 작성 중이던 글이 있으면 보관했다가
  발송 후 그대로 되돌려 놓습니다.
- **클립보드를 원상복구**합니다. 발송에 클립보드를 쓰지만 끝나면 원래 내용으로 되돌립니다.
- 전송 여부를 **입력창이 비워졌는지로 확인**하고, 안 나갔으면 성공으로 보고하지 않습니다.

---

## 알아 두실 점

- **오전 6시에 PC가 켜져 있어야 합니다.** 절전 상태면 깨워서 실행하도록
  (`-WakeToRun`) 등록했지만, 완전히 꺼져 있으면 실행되지 않습니다.
  작업은 '놓친 경우 가능할 때 실행'으로 설정돼 있어, PC를 켜면 그날 것을 뒤늦게 보냅니다.
- **발송 몇 초 동안 채팅창이 화면 앞으로 나옵니다.** 실제 키 입력이 필요해서입니다.
  오전 6시 실행이라 평소에는 보이지 않습니다.
- **카카오 운영정책상 자동화 도구 사용은 계정 이용제한 소지가 있습니다.**
  개인 계정으로 본인 단톡방에 하루 한 번 보내는 정도라 위험은 낮지만, 0은 아닙니다.
  발송 빈도를 늘리지 않는 것을 권합니다.

## 홈페이지에서 예약 발송하기

설교 매니저에서 **예배 종류를 '매일 QT'(또는 새벽기도)로** 두면 상단에
`💬 카카오톡 복사` 옆에 **`⏰ 예약 발송`** 버튼이 나타납니다.

누르면 원고가 저장된 뒤 예약창이 열립니다.

1. **보낼 내용** — 카카오톡 복사와 똑같은 양식이 채워져 있습니다. 여기서 고쳐도 됩니다.
   예약한 내용이 그대로 저장되므로, 나중에 원고를 고쳐도 **예약분은 바뀌지 않습니다.**
2. **보낼 채널** — 여러 방을 한 번에 고를 수 있습니다. 고른 방마다 예약 1건이 만들어집니다.
3. **발송 시각** — `설교일 06:00` · `내일 06:00` · `1시간 뒤` 단추로 빠르게 넣을 수 있습니다.
4. **⏰ 예약하기** — 확인 후 예약됩니다. 아래 **예약 내역**에서 상태를 보고 취소할 수 있습니다.

### 채널(단톡방) 등록

예약창의 **＋ 채널 추가**로 등록합니다. 방 이름은 **카카오톡에 보이는 그대로** 넣어야 합니다.
이름이 다르면 워커가 발송하지 않고 멈춥니다(오발송 방지).

더 이상 쓰지 않는 방은 지우지 말고 **중지**로 두면 목록에서 선택할 수 없게 됩니다.

### 처음 한 번 — 데이터베이스와 워커

1. Supabase SQL Editor에서 **`supabase/20260921_2345_kakao_send_jobs.sql`** 을 1회 실행합니다.
   (실행 전에는 예약창에 "Supabase SQL Editor에서 … 실행해 주세요" 안내가 뜹니다)
2. 발송을 맡을 PC에서 **`tools/카카오예약워커.bat`** 을 켜 둡니다.
   30초마다 확인해서 예약 시각이 된 것을 보냅니다.
   환경변수 `SUPABASE_SERVICE_ROLE_KEY` 가 있어야 하며, 다른 워커와 같은 값을 씁니다.
   집·교회 PC 두 대를 동시에 켜 두어도 한 건이 두 번 가지 않습니다.
3. 매번 켜기 번거로우면 **`tools/카카오워커_자동시작_켜기.bat`** 을 한 번 실행하세요.
   윈도우에 로그인할 때마다 워커가 자동으로 뜹니다. (끄기: `카카오워커_자동시작_끄기.bat`)

> **발송 PC는 카카오톡이 로그인된 그 PC여야 합니다.** 매일 자동 발송(작업 스케줄러)과
> 예약 워커를 서로 다른 PC에 두면, 로그인 안 된 쪽은 계속 실패합니다. 한 PC로 모으세요.

> **같은 방·같은 날에 매일 자동 발송과 예약 발송을 겹치게 두지 마세요.** 둘은 서로를
> 모르기 때문에 두 번 발송됩니다. 매일 보내는 방은 작업 스케줄러에 맡기고,
> 예약 발송은 다른 방이나 다른 시각에 쓰는 것을 권합니다.

### 예약 상태

| 상태 | 뜻 |
| --- | --- |
| 예약됨 | 아직 시각이 안 됨 (취소 가능) |
| 발송 중 | 워커가 가져가 보내는 중 |
| 발송 완료 | 단톡방에 올라감 |
| 실패 | 사유가 함께 표시됨 |
| 취소됨 | 사람이 취소함 |

> **예약 시각에 PC가 꺼져 있었다면** — 워커는 너무 늦은 예약을 보내지 않습니다.
> 기본 6시간이 지나면 보내지 않고 '실패'로 남깁니다(새벽 QT가 한밤중에 날아가는 것을 막기 위함).
> 이 시간은 환경변수 `KAKAO_MAX_LATE_HOURS` 로 바꿀 수 있습니다.

## 문제가 생기면

먼저 `tools/logs/kakao_qt.log` 를 봅니다. 중단 사유가 한국어로 기록됩니다.

| 로그 메시지 | 조치 |
| --- | --- |
| `카카오톡이 로그아웃되어 로그인 창이 떠 있습니다` | **가장 흔한 원인.** 카카오톡에 다시 로그인하고 '자동 로그인'을 켜세요. 로그아웃 상태에서는 채팅·친구 목록이 통째로 비어 있어 방을 찾을 수 없습니다 |
| `카카오톡 로그인 창을 넘어가지 못했습니다` | 자동 로그인 설정 확인 |
| `ModuleNotFoundError: No module named 'win32api'` | 이제는 스크립트가 알아서 설치합니다. 그래도 나면 `pip install pywin32` 를 직접 실행 |
| `잠금모드가 켜져 있어` | 잠금모드 해제 |
| `방을 열지 못했습니다` | `kakao_qt_config.json` 의 방 이름이 실제와 같은지 확인 |
| `열린 창 제목이 다릅니다` | 같은 이름의 다른 방이 먼저 검색된 경우 — 방 이름을 더 정확히 |
| `입력창에 제대로 들어가지 않아` | 카카오톡이 응답 중이 아닌지 확인 후 재실행 |
| `전송되지 않았습니다` | 카카오톡 업데이트로 창 구조가 바뀌었을 수 있음 — 재점검 필요 |

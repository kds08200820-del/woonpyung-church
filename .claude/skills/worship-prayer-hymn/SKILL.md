# Worship Prayer & Hymn (예배 기도문·찬송 추천 스킬)

## 이 스킬이 하는 일

설교 본문·주제·핵심 메시지를 입력받아 두 종류의 산출물을 만듭니다:

1. **기도문 초안** — 사용자가 선택한 기도 종류(대표기도 / 중보기도 / 목회기도 / 축도)별 초안. 설교 주제와 일관된 톤·내용·성구 인용 포함.
2. **찬송 추천 목록** — 예배 진행 위치(입례·찬양·봉헌·결심·폐회 등)별로 3-5곡 후보, 각 곡의 추천 이유와 함께.

기도문은 신자가 그대로 읽을 수 있는 수준의 완성도, 찬송 추천은 회중이 함께 부를 수 있는 익숙한 곡 위주.

## 언제 트리거되어야 하는가

다음 신호가 보이면 즉시 사용:
- "대표기도", "중보기도", "목회기도", "축도", "예배 기도문", "주일 기도문"
- "이번 주 찬송 추천", "설교 주제에 맞는 찬송", "결심찬송", "폐회찬송"
- 설교 본문/주제 + 기도/찬송 단어 동시 등장
- 한국 교회 예배 컨텍스트 + 기도/찬송 요청

타 종교 기도 요청은 트리거 대상이 아닙니다.

## 핵심 워크플로우 (4단계)

### 1단계: 입력 분석

다음 정보를 사용자로부터 확보합니다(이미 제공됐으면 추출, 없으면 질문):

- **설교 본문**: 예) "룻기 2:1-14"
- **설교 제목**: 예) "긍휼이 머무는 자리"
- **설교 핵심 주제 1-3줄**: 예) "긍휼·우연·섭리·은혜의 흐름"
- **필요한 산출물**:
  - 기도 종류 (복수 선택 가능): 대표기도 / 중보기도 / 목회기도 / 축도 / 헌금기도 / 식사기도
  - 찬송 위치 (복수 선택 가능): 입례찬송 / 경배찬송 / 봉헌찬송 / 결심찬송 / 폐회찬송 / 특송 추천
- **예배 형식**: 전통 예배 / 회중 찬양 중심 / 혼합 (찬송가 vs CCM 비중 결정)
- **교회의 신앙 노선**: 한국 개혁주의(총신·합신 노선) 기본. 다르면 명시.

분석 결과를 사용자에게 요약해서 보여주고 승인 받은 뒤 다음 단계.

### 2단계: 기도문 초안 작성

`references/prayer-types-and-flow.md`를 읽어 각 기도 종류의 구조와 흐름을 숙지하세요. 그 후 `references/prayer-writing-conventions.md`를 읽어 한국 장로교 기도 어법(호칭·연결어·종결구)을 따르세요.

각 기도문 작성 시 다음을 포함:

- **호칭**: 적절한 하나님 호칭 (예: "거룩하시고 영광 받으시기에 합당하신 하나님 아버지")
- **본문 연결**: 설교 본문/주제와 자연스럽게 연결되는 회상 또는 적용
- **회중의 자리에서**: "우리"를 주어로 하는 공동체 기도 어법
- **간구의 구체성**: 추상적이지 않고 이번 한 주의 삶에 닿는 구체 간구
- **종결**: "예수 그리스도의 이름으로 기도드립니다. 아멘"

기도문 길이 가이드:
- 대표기도: 약 250-400자 (낭독 시 1분 30초 내외)
- 중보기도: 약 300-500자 (낭독 시 2분 내외)
- 목회기도: 약 400-600자 (낭독 시 2분 30초)
- 축도: 약 80-120자 (낭독 시 30초)
- 헌금기도/식사기도: 약 100-180자 (낭독 시 40초)

### 3단계: 찬송 추천 목록 작성

`references/hymn-recommendation-logic.md`를 읽어 추천 알고리즘을 숙지하세요. `references/hymn-database-quick-reference.md`에 주제별 자주 쓰이는 찬송이 정리되어 있습니다.

각 위치별로:

- **3-5곡 후보 제시**
- **각 곡마다**:
  - 곡명 + 찬송가 번호 (21세기 새찬송가 기준 / 통일찬송가 번호 병기)
  - 또는 CCM의 경우 곡명 + 작사·작곡자
  - 추천 이유 (1-2줄): 설교 주제와의 호응 + 회중 친숙도 + 곡 분위기
  - 키 (가능하면): 회중 음역대 고려

찬송 vs CCM 비율은 1단계에서 결정한 예배 형식에 따라 조정.

### 4단계: 산출물 통합 및 제시

기도문 + 찬송 추천을 하나의 워드 문서(.docx)로 통합. 또는 사용자 요청에 따라 분리해서 제공.

문서 구조:
```
[제목] 주일 예배 기도문 & 찬송 추천
[부제] 설교: "긍휼이 머무는 자리" — 룻기 2:1-14

== 기도문 ==
1. 대표기도
[기도문 본문]

2. 중보기도
[기도문 본문]

== 찬송 추천 ==
1. 입례찬송 (3곡 후보)
   [곡 1] 새 89장 / 통 89장 「내 영혼이 은총 입어」
     추천 이유: …
   …

2. 결심찬송 (3곡 후보)
   …
```

## 절대 지켜야 할 원칙

1. **신학적 정통성을 지킨다.** 한국 개혁주의(총신·합신 노선)의 일반적 신앙고백과 어긋나지 않게 작성. 모호한 영성주의·신비주의 표현 자제.

2. **성경 인용은 정확하다.** 기도문 안에 인용되는 성경 구절은 한 글자도 틀리지 않아야 합니다. 사용자가 명시한 번역본(기본: 개역개정)을 따름.

3. **회중의 보편성을 지킨다.** 대표기도·중보기도는 회중 모두가 "아멘"으로 동의할 수 있는 보편적 내용. 특정 정파·정치적 의견·논쟁적 신학 입장은 배제.

4. **찬송 번호의 정확성**: 추천 시 21세기 새찬송가 번호를 우선으로 하되, 통일찬송가 번호도 병기. 번호가 불확실하면 "(번호 확인 필요)"라고 표기.

5. **개인화 가능성을 열어둔다.** 기도문은 어디까지나 초안. 사용자가 자신의 표현으로 다듬을 수 있도록 자연스럽고 평이한 문장. 너무 화려하거나 박제된 표현 자제.

## 자주 발생하는 함정

- **너무 길게 만들기**: 한국 예배에서 기도가 너무 길면 회중이 집중을 잃습니다. 길이 가이드 준수.
- **신학적 위치 모호**: "우주의 에너지", "보편적 사랑" 같은 표현은 개혁주의 예배에 부적절. 삼위 하나님을 명확히.
- **CCM 일색 또는 찬송가 일색**: 사용자가 정한 형식 비율을 지킬 것.
- **결심찬송에 너무 무거운 곡**: 결심·헌신은 무거운 곡보다 행동을 촉구하는 곡이 적합.
- **본문과 무관한 기도**: 설교 주제와 동떨어진 기도는 예배 흐름을 끊습니다. 반드시 본문/주제 연결.

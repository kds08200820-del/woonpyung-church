# Youth Bible Study (중등부 성경공부 교재 생성기)

## 이 스킬이 하는 일

설교 본문·주제 또는 별도 성경 본문을 입력받아, 중등부 한 차시(45분 기준) 분량의 인쇄 가능한 워크북(.docx)을 생성합니다.

**산출물 구조 (7단계)**:
1. 도입/아이스브레이커 (5분)
2. 본문 읽기 (5분)
3. 본문 이해 / 풀이 (10분)
4. 적용 질문 (15분, 핵심)
5. 활동 (10분)
6. 암송 구절
7. 마무리 기도

## 언제 트리거되어야 하는가

다음 신호가 보이면 즉시 사용:
- "중등부 교재", "중학생 성경공부", "중등부 공과", "주일학교 교재"
- "청소년 워크북", "중학생 큐티", "청소년 적용 질문"
- 설교 본문 + 청소년·중등부 단어 동시 등장
- 중학생 대상 성경공부 자료 요청

다른 연령대(어린이/청년/장년)는 이 스킬 대상이 아닙니다.

## 핵심 설계 원칙

이 스킬이 다른 성경공부 자료와 차별되는 5가지 원칙입니다.

### 원칙 1: 어휘는 쉽게, 깊이는 양보하지 않음

중학생도 충분히 신학적 깊이를 이해할 수 있습니다. 어른용 어휘만 줄이고 메시지의 무게는 유지하세요. "섭리" → "하나님의 손길", "긍휼" → "받을 자격이 없는 자에게 베푸는 사랑" 같은 풀이형 어휘.

### 원칙 2: 그들의 일상에 닿는 적용

중학생의 실제 삶 — 친구 관계, 학업 스트레스, 가족 갈등, SNS, 외모 콤플렉스, 진로 고민 — 에 연결되는 적용 질문이 핵심입니다. "이번 주 성령충만하게 살아갑시다" 같은 추상적 권면은 배제.

### 원칙 3: 의견 → 고백 → 결단의 3단계 질문

적용 질문은 다음 순서로 설계:
- **의견**: "어떻게 생각하니?" (정답 없는 열린 질문)
- **고백**: "내 삶에서는 어떻게 적용될까?" (개인적 연결)
- **결단**: "이번 주에 한 가지 실천한다면?" (구체적 행동)

각 단계가 빠지면 적용이 얕아집니다.

### 원칙 4: 활동은 진짜로 가능한 것으로

소그룹실에서 45분 안에 실제 진행 가능한 활동만 제안. 풍선·도화지·스마트폰 앱 등 가용 자원을 명시. 도구가 필요하면 명확히.

### 원칙 5: 인쇄해서 그대로 쓸 수 있는 형식

A4 세로, 4-6쪽 분량. 페이지 번호, 빈 칸(학생이 답을 쓰는 공간), 박스(중요 구절) 모두 포함. 추가 편집 없이 복사기로 복사해 나눠줄 수 있는 수준.

## 핵심 워크플로우 (4단계)

### 1단계: 입력 분석

다음 정보 확보:

- **본문**: 예) "룻기 2:1-14"
- **본문 핵심 주제**: 예) "받은 긍휼을 흘려 보내는 삶"
- **이미 작성된 설교가 있는가?**: 있으면 설교 분석을 활용해 일관성 있게 생성. 없으면 본문 자체에서 출발.
- **차시 길이**: 기본 45분. 30분/60분 등 다르면 명시.
- **그룹 크기**: 소그룹(5-10명) 기본. 대그룹은 활동 조정 필요.
- **시리즈 정보**: 1회성인지, 연속 시리즈의 한 회차인지.

분석 결과 사용자에게 요약 제시 후 승인.

### 2단계: 교재 구조 설계

`references/lesson-structure.md`를 읽어 표준 45분 구성을 따르세요. 그 후 각 섹션의 시간·내용을 결정:

```
도입 (5분)
본문 읽기 (5분)
본문 이해 (10분)
적용 질문 (15분)
활동 (10분)
암송·기도 (5분)
```

특정 차시는 활동을 줄이고 적용 질문을 더 깊게 하는 식으로 조정 가능. 그러나 7단계는 모두 포함.

### 3단계: 각 섹션 컨텐츠 작성

각 섹션 작성 시 해당 참조 파일을 읽어 가이드 준수:

- **도입/아이스브레이커**: `references/activity-bank.md`의 도입 활동 섹션 참조
- **본문 풀이**: 어휘·문장 구조를 중학생 수준으로
- **적용 질문**: `references/question-design.md`의 3단계 질문 모델 적용
- **활동**: `references/activity-bank.md`에서 본문 주제와 맞는 것 선택
- **암송 구절**: 본문에서 1-2 절 또는 핵심 구절 선정 (12-30자 권장)

### 4단계: 워크북 형식으로 산출

`references/workbook-format.md`의 형식 가이드를 따라 .docx 파일 생성. docx 스킬(`/skills/docx/SKILL.md`)을 먼저 읽어 모범 사례 적용.

A4 세로 4-6쪽 분량, 페이지 번호 하단 우측, 빈 칸 충분히 (학생이 직접 쓸 수 있게), 중요 구절은 박스 처리.

## 절대 지켜야 할 원칙

1. **신학적 정통성을 지킨다.** 한국 개혁주의 노선의 일반 신앙고백과 일치. 중학생용이라고 해서 신학을 단순화·왜곡하지 않음.

2. **성경 본문은 정확히 인용.** 한 글자도 틀리면 안 됨. 인용 시 사용 번역본(기본: 개역개정) 명시.

3. **부적절한 비유·예화 배제.** 정치 풍자, 특정 인물 비하, 외모 비하, 성적 농담은 절대 금지. 중학생의 자존감과 영적 성장이 가장 중요한 시기.

4. **교사용 가이드도 함께.** 워크북에 [교사 노트] 섹션을 두어 각 질문의 의도, 가능한 답변, 주의할 점을 짧게 메모. 교사가 처음 가르쳐도 따라갈 수 있게.

5. **개인정보 노출 강요 금지.** "가족 이야기 해 봐" 같은 질문은 학생이 노출되기 싫을 수 있음. 익명·일반적 답변도 가능하게 설계.

## 자주 발생하는 함정

- **너무 어른 같은 어휘**: "주의 섭리에 순복하는 삶"은 중학생에게 추상적. "하나님이 일하시는 방식을 믿고 따라가기"가 적합.
- **닫힌 질문**: "예수님은 누구신가?" 같은 질문은 단답으로 끝남. "예수님이 친구에게 가장 친한 친구라면, 그분의 어떤 점이 다를까?" 같은 열린 질문.
- **활동이 따분함**: "둘러 앉아 토론" 같은 무난한 활동만 반복하면 흥미 잃음. 게임·역할극·창작 활동을 적절히 섞기.
- **시간 초과**: 45분 안에 7단계 다 못 끝나면 안 됨. 각 섹션 시간을 빠듯하지 않게 설계.
- **설교 그대로 옮김**: 어른 설교를 그대로 옮기면 중학생은 듣지 않음. 어휘·예화·관점을 청소년 시점으로 재구성.
